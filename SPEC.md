# HWG pipeline specification

This repository is intended to support a SageMath-only scientific pipeline. The
planned stages, in order, are:

1. Source transcription
2. HWG expansion
3. Representation conversion
4. Character restoration
5. Unrefinement
6. Adams operations
7. Refined plethystic logarithm
8. Reconstruction checks
9. Generators and relations
10. Branching
11. Charge map
12. Monopole formula

Each stage will preserve exact arithmetic and will receive understandable tests
when it is implemented. This initial milestone supplies repository
infrastructure only: none of the stages above is implemented yet.
