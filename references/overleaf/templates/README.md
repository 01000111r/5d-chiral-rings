# Approved QFFF report format

These files define the approved presentation format for generated reports.

## Structural references

- `hilbert_plethystic_reference.tex`
- `branching_charge_map_reference.tex`
- `qfffcalc.sty`

The mathematics in the two reference documents is specific to `SU(3)+5F`, `|k|=1/2`. Only the presentation, structure, typography, sign handling, page breaking, and concise prose style are to be generalized.

## Visual references

The PNG files under `visual_reference/` are page-by-page renders of the approved PDFs and are the authoritative visual target:

- `visual_reference/hilbert_plethystic/page-01.png` through `page-12.png`
- `visual_reference/branching_charge_map/page-01.png` through `page-25.png`

The PNG page number matches the corresponding PDF page number.

## Source-of-truth policy

The repository's theory YAML, branching specifications, charge-map specifications, and exact generated mathematical evidence remain authoritative. These references must not be used to copy case-specific coefficients, representations, charges, symmetries, or literature statements into other theories.
